# Customer Churn Prediction 📊

## 🔍 Overview
This project predicts customer churn using machine learning techniques. The objective is to identify customers who are likely to discontinue services and provide insights to improve customer retention.

## 🧠 Problem Statement
Customer churn directly impacts revenue. By analyzing customer behavior and service usage patterns, this project builds a predictive model to identify churn-prone customers.

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## 📂 Dataset
Telco Customer Churn Dataset (Kaggle)

## ⚙️ Workflow
1. Data cleaning and preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Feature engineering and encoding  
4. Model training (Logistic Regression, Random Forest)  
5. Model optimization (class balancing, hyperparameter tuning)  
6. Performance evaluation using Accuracy and ROC-AUC  

## 📈 Results
- Improved churn detection using optimized Logistic Regression
- Key churn drivers identified:
  - Low customer tenure
  - High monthly charges
  - Month-to-month contracts

## 🧪 Model Performance
- Accuracy: 0.762%
- ROC-AUC Score: 0.8696

## 📌 Conclusion
This project demonstrates a complete end-to-end data science pipeline and highlights how data-driven insights can support business decision-making.
